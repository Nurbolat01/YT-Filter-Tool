# 🛑 YT Filter Tool

**YT Filter Tool** — это жесткое Chrome-расширение для тех, кто хочет перестать сливать время на залипание в YouTube. 

Оно убирает главную причину прокрастинации — яркие кликбейтные обложки и бесконечную ленту Shorts.

## 🔥 Что делает расширение

Мозг триггерится не на сам факт существования видео, а на его **дофаминовую обложку**. Нет обложки — нет желания кликать.

* **Полное удаление Shorts:** Вырезает блоки Shorts из поиска, рекомендаций и боковой панели.
* **Блокировка по ключевым словам:** Введи свои триггеры (например, *CS2, CS:GO, s1mple*). Расширение мгновенно накроет обложки этих видео плакатом «НЕ ТРОГАЙ!».
* **Неотменяемая система штрафов:** Решил сорваться и кликнуть? Включится **5-минутный таймер**, который отправит тебя подумать над своим поведением под воспитательное видео. Только после отсчета откроется целевой ролик.
* **Синхронизация на лету:** Добавляй или удаляй слова в настройках — страница YouTube подтягивает изменения мгновенно без перезагрузки.

## 📥 Как установить

1. Скачай этот репозиторий (нажми зеленую кнопку **Code** $\rightarrow$ **Download ZIP**) и распакуй в любую папку.
2. Открой браузер и перейди по адресу: `chrome://extensions/`
3. Включи **Режим разработчика** (переключатель в правом верхнем углу).
4. Нажми кнопку **Загрузить распакованное расширение** (Load unpacked) и выбери папку с проектом.
